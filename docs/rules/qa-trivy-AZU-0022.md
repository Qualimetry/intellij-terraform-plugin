# Ensure databases are not publicly accessible

`qa-trivy-AZU-0022` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

Database resources should not be publicly available. You should limit all access to the minimum that is required for your application to function. Disable public access to database when not required.
