# Ensure the activity retention log is set to at least a year

`qa-trivy-AZU-0031` &middot; Maintainability &middot; Code Smell &middot; severity MINOR

## Summary

The average time to detect a breach is up to 210 days, to ensure that all the information required for an effective investigation is available, the retention period should allow for delayed starts to investigating. Set a retention period that will allow for delayed investigation.
