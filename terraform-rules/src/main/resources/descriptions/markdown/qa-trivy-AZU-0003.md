# App Service authentication is activated

`qa-trivy-AZU-0003` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

Enabling authentication ensures that all communications in the application are authenticated. The auth_settings block needs to be filled out with the appropriate auth backend settings. Enable authentication to prevent anonymous requests being accepted.
