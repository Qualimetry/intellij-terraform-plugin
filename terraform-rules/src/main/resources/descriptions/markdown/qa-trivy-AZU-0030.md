# Roles limited to the required actions

`qa-trivy-AZU-0030` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

The permissions granted to a role should be kept to the minimum required to be able to do the task. Wildcard permissions must not be used. Use targeted permissions for roles.
