# Web App has registration with AD enabled

`qa-trivy-AZU-0002` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

Registering the identity used by an App with AD allows it to interact with other services without using username and password. Register the app identity with AD.
