# Send notification emails for high severity alerts

`qa-trivy-AZU-0044` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

It is recommended that at least one valid contact is configured for the security center. Microsoft will notify the security contact directly in the event of a security incident using email and require alerting to be turned on. Set alert notifications to be on.
