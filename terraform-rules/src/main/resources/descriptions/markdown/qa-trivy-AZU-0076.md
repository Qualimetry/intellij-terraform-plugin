# Network interfaces with public IP

`qa-trivy-AZU-0076` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

Avoid assigning public IP addresses to network interfaces unless necessary. Remove public IP addresses from network interfaces unless they are specifically required for internet connectivity.
