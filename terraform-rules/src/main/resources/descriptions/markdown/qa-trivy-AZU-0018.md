# At least one email address is set for threat alerts

`qa-trivy-AZU-0018` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

SQL Server sends alerts for threat detection via email, if there are no email addresses set then mitigation will be delayed. Provide at least one email address for threat alerts.
