# The required contact details should be set for security center

`qa-trivy-AZU-0046` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

It is recommended that at least one valid contact is configured for the security center. Microsoft will notify the security contact directly in the event of a security incident and will look to use a telephone number in cases where a prompt response is required. Set a telephone number for security center contact.
