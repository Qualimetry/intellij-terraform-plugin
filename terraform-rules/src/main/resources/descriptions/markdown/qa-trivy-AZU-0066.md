# Ensure AKS cluster has Azure Policy add-on enabled

`qa-trivy-AZU-0066` &middot; Security &middot; Vulnerability &middot; severity MINOR

## Summary

Azure Kubernetes Service should enable Azure Policy Add-On to enforce compliance and governance policies on the cluster. The add-on extends Gatekeeper v3, an admission controller webhook for Open Policy Agent (OPA). Enable Azure Policy add-on on the AKS cluster to enforce governance policies.
